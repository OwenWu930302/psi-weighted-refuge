## 4. 訓練集：被加權病例的加權前後

### 4.1 對 baseline（初步；含回歸平均，見 4.2）

**被加權病例（各 120 例）**

| 專家 | 加權前 | 加權後 | Δ | ΔOD | ΔOC | 升 / 降 | Wilcoxon p |
|---|---|---|---|---|---|---|---|
| Ψ1 | 0.9722 | 0.9701 | −0.0021 | −0.0063 | +0.0021 | 53 / 67 | 0.12 |
| Ψ5 | 0.9719 | 0.9684 | −0.0034 | −0.0056 | −0.0013 | 41 / 79 | 1.2e-04 |
| Ψ8 | 0.9731 | 0.9708 | −0.0022 | −0.0035 | −0.0010 | 49 / 71 | 0.016 |

**加權組 vs 未加權組**

| 專家 | 加權組 Δ | 升 / 降 | 未加權組 Δ | 升 / 降 | 差距 | Mann-Whitney p | 整體 Δ |
|---|---|---|---|---|---|---|---|
| Ψ1 | −0.0021 | 53 / 67 | −0.0030 | 103 / 177 | +0.0008 | 0.32 | −0.0027 |
| Ψ5 | −0.0034 | 41 / 79 | −0.0083 | 43 / 237 | **+0.0049** | **4.5e-05** | −0.0068 |
| Ψ8 | −0.0022 | 49 / 71 | −0.0026 | 108 / 172 | +0.0004 | 0.90 | −0.0025 |

三個專家在訓練集的整體 Dice 都低於 baseline（Ψ1 0.9726、Ψ5 0.9685、Ψ8 0.9728）。差距皆為正，但只有 Ψ5 顯著。

### 4.2 安慰劑檢查

**回歸平均**：未加權病例中，Δ 對 baseline Dice 的斜率為 −0.885（Ψ1 專家）、−0.794（Ψ5）、−0.658（Ψ8），r ≈ −0.5，p < 1e-16。
baseline 分數越低的病例，換一個模型重新預測後回升越多；清單病例的 baseline Dice 偏低，因此 4.1 的差距會被高估。

**差距矩陣**（列 = 模型，欄 = 清單；◆ = 真正被加權，其餘 = 在該模型中未被加權的病例）

| | Ψ1 清單 | Ψ5 清單 | Ψ8 清單 |
|---|---|---|---|
| **原始差距** | | | |
| Ψ1 專家 | ◆ +0.0008 | +0.0018 | +0.0002 |
| Ψ5 專家 | −0.0023 | ◆ **+0.0049**\*\*\* | −0.0015 |
| Ψ8 專家 | −0.0005 | +0.0012 | ◆ +0.0004 |
| **控制 baseline Dice 後** | | | |
| Ψ1 專家 | ◆ −0.0015 | −0.0002 | −0.0013 |
| Ψ5 專家 | −0.0036\*\* | ◆ +0.0023 | −0.0029\* |
| Ψ8 專家 | −0.0024\* | −0.0004 | ◆ −0.0016 |

\* p < 0.05　\*\* p < 0.01　\*\*\* p < 0.001（控制後為分層置換檢定，10,000 次）

**線性迴歸 Δ ~ 加權 + baseline Dice**（真正被加權的係數）：Ψ1 −0.0012（p = 0.26）、Ψ5 +0.0009（p = 0.36）、Ψ8 −0.0018（p = 0.044）。

**解讀**
1. 控制 baseline Dice 後，三個專家的被加權病例都沒有比 baseline Dice 相近的未加權病例更好；Ψ5 的 +0.0049 主要來自回歸平均。
2. 「Ψ1 清單」的病例在其他兩個模型中（未被加權）控制後顯著下降（−0.0036、−0.0024），在 Ψ1 專家中為 −0.0015。Ψ1 高的病例在重新訓練後本來就傾向變差；Ψ1 專家中下降較少，可能有少量加權效果，但未達顯著。
3. psi-weighted-nnunet 的 ACDC 以另外訓練的對照組（ps1ctrl）為加權前，回歸平均兩邊抵消，不受此問題影響。REFUGE 的最終結論以對照組完成後的 4.3 為準。

## 6. 與 BTCV、ACDC 的比較（初步）

| | 被加權病例（同一種 loss 下） | 加權組 − 未加權組 |
|---|---|---|
| ACDC（vs ps1ctrl） | 四個專家皆上升（Ψ1、Ψ6、Ψ7 逐例全升） | +0.009 至 +0.011 |
| BTCV（對齊版 vs allctrl） | 三個專家逐例全升 | 約 +0.005 |
| REFUGE（vs baseline，控制回歸平均後） | 無顯著改善 | −0.0016 至 +0.0023（皆不顯著） |

可能原因：FunduSegmenter 以 validation 最佳 epoch 選模型（各模型訓練量不同）、訓練集已接近飽和、encoder 凍結、REFUGE 上的 Ψ（特別是 Ψ5）較少對應模型錯誤。詳見 [METHODS.md](METHODS.md) 第 8 節。
